# Definition of Ready (DoR) — Shop-Inventory

Тарихша спринтке кіру үшін келесі шарттар орындалуы керек:

| № | Критерий | Тексеру тәсілі |
|---|---|---|
| 1 | Тарихша форматында жазылған (рөл, әрекет, пайда) | GitHub Issue мәтіні |
| 2 | Қабылдау критерийлері Given–When–Then форматында | Issue-тегі чек-лист |
| 3 | Story point-пен бағаланған | Issue өрісіндегі баға |
| 4 | Эпикке байланған | Issue-тегі Label/Epic |
| 5 | Дизайн дайын (егер UI болса) | Figma сілтемесі |
| 6 | Тәуелділіктер анықталған | Issue-тегі байланыстар |
| 7 | Өлшемі 8 SP-тан аспайды | Егер асса — бөлшектеу керек |
