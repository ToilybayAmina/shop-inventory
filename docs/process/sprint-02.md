# 2-спринт — «Сатуды болдырмау және Қарыз»

**Мерзімі:** 7–8 апта (2 апта)
**Мақсаты:** Сатуды болдырмау, қарызға сату және дабыл жұмыс істейді.

## Спринт жоспары (18 SP)

| № | Тарихша | SP |
|---|---|---|
| 1 | SHI-7: Сатуды болдырмау | 5 |
| 2 | SHI-10: Төмен қалдық дабылы | 3 |
| 3 | SHI-11: Қарызға сату | 5 |
| 4 | SHI-12: Қарызды өтеу | 5 |
| **Барлығы** | | **18 SP** |

## Ретроспектива (2-спринт)

**Не жақсы болды:**
- WIP = 2 ережесі толық сақталды (1-спринт ретро әрекеті нәтиже берді).
- API келісімі тез болды.

**Не нашар болды:**
- SHI-7 әлі де үлкен (5 SP).
- Қарыз логикасы күрделі болды.
- Кассир UAT-қа келмеді.

**Қабылданған өлшенетін әрекеттер (3-спринтке):**
1. 5 SP тарихшаларды міндетті түрде 3+2 етіп бөлу.
2. UAT күнін алдын ала (спринт басында) бекіту.
3. Қарыз есебіне unit test көбейту.
