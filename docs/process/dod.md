# Definition of Done (DoD) — Shop-Inventory

Тарихшаны «Done» бағанына өткізу үшін келесі шарттар орындалуы керек:

| № | Критерий | Тексеру тәсілі |
|---|---|---|
| 1 | Код жазылған және GitHub-қа жүктелген | Pull Request |
| 2 | Code review өткен (кемінде 1 мақұлдау) | PR-дағы Approve |
| 3 | Unit test coverage ≥ 70% | CI-дегі Codecov есебі |
| 4 | CI-де барлық тест жасыл | GitHub Actions |
| 5 | Функционалдық талап орындалған | Қабылдау критерийлері |
| 6 | Қабылдау критерийлері тексерілген | QA тексеруі |
| 7 | Құжаттама жаңартылған | README немесе Wiki |
| 8 | Demo-да көрсетілген | Апталық демо жазбасы |
