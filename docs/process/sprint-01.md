## Ретроспектива (1-спринт)

**Не жақсы болды:**
- MVP жұмыс істейді.
- Code review тез өтті.

**Не нашар болды:**
- WIP шектеуі сақталмады (3-4 тапсырма қатар алынды).
- Backend/Frontend интеграциясы кеш болды.
- SHI-5 (5 SP) тым үлкен болып, бөлшектеу қажет болды.

**Қабылданған өлшенетін әрекеттер (2-спринтке):**
1. **WIP = 2** ережесін қатаң сақтау.
2. API келісімін спринттің бірінші күнінде бекіту.
3. 5 SP-тан үлкен тарихшаларды бөлшектеу.
