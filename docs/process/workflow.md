# Жұмыс процесі — Shop-Inventory

## Тақта бағандары және WIP (Work In Progress) шектеулері

| № | Баған | Сипаттама | WIP Limit |
|---|---|---|---|
| 1 | **Backlog** | Барлық жаңа тарихшалар | Шексіз |
| 2 | **Ready** | DoR-дан өткен, спринтке дайын | 5 |
| 3 | **In Progress** | Белсенді әзірленіп жатқан | **2** |
| 4 | **Review** | Code review / тестілеу | 3 |
| 5 | **Done** | DoD-дан өткен | Шексіз |

## Ауысу саясаттары (Transition Rules)

1. **Backlog → Ready:** DoR-дың 7 критерийі орындалғанда ғана.
2. **Ready → In Progress:** «In Progress» бағанында бос орын (WIP < 2) болғанда ғана.
3. **In Progress → Review:** Код жазылып, жергілікті тест өткенде.
4. **Review → Done:** DoD-дың 8 критерийі орындалғанда ғана.
