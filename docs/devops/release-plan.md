# Релиз жоспары және кері қайтару (Rollback)

* **Релиз терезесі:** Жұма күндері, сағат 18:00.
* **Жауаптылар:**
  - Релиз менеджері: Студент А (PM)
  - Техникалық деплой: Студент В (Backend)
  - QA тексеру: Студент Г (QA)

## 2. Релиз чек-листі
- [ ] Барлық тесттер CI-де жасыл.
- [ ] Trivy осалдықтарды таппады.
- [ ] Дерекқордың backup-ы алынды.
- [ ] `main` тармағындағы код `v1.0.0` тегімен белгіленді.
- [ ] Деплой жасалды (Docker Compose).

## 3. Кері қайтару жоспары (Rollback Plan)
Егер релизден кейін критикалық қате шықса:
1. **Дереу хабарлау:** Релиз менеджері мен дүкен иесіне.
2. **Кодты кері қайтару:** `git revert <commit-hash>` жасап, алдыңғы тұрақты нұсқаны қайта деплой ету.
3. **Дерекқорды қалпына келтіру:** Егер миграция қате болса, релиз алдындағы backup-ты қайта жүктеу.
4. **Талдау:** 24 сағат ішінде post-mortem жазу.
