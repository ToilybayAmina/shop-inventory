## 2. Ескертулерді бөлу (Feedback Triage)

UAT кезінде табылған қателер келесі санаттарға бөлінді:
1. **Ақаулар (Bugs):** Төмен қалдық дабылы дұрыс істемейді → GitHub-қа `[Bug]` ретінде бекітілді (High priority).
2. **Нақтылаулар (Clarifications):** Чекте ЖСН болуы керек → Жаңа талап ретінде қабылданды.
3. **Өзгеріс сұраныстары (Change Requests):** Кассирге түнгі ауысым үшін Dark mode керек → V2 релизіне жоспарланды.
