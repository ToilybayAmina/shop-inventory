# Атау келісімі

## Тармақтар (branches)
- `feature/` — жаңа функция
- `bugfix/` — қате түзету
- `docs/` — құжаттама

## Тапсырмалар (issues)
- `[Task]` — қарапайым тапсырма
- `[Bug]` — қате
- `[Story]` — пайдаланушы хикаясы

## Коммиттер (commits)
- `feat:` — жаңа функция
- `fix:` — қате түзету
- `docs:` — құжаттама

## Мысалдар
- Тармақ: `feature/add-product-form`
- Коммит: `feat: add product form`
- Тапсырма: `[Task] Тауарларды қабылдау формасын жасау`
