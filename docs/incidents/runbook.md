# RUNBOOK (Жұмыс істеу нұсқаулығы)

**Сценарий:** «Сайт істемейді (500 Internal Server Error)» қатесі шыққанда не істеу керек?

| Қадам | Әрекет | Жауапты |
|---|---|---|
| **1** | Uptime Kuma-дан хабарлама келгенін тексеру. Сайтқа кіруге тырысып көру. | Кезекші әзірлеуші |
| **2** | Серверге (VPS) SSH арқылы кіріп, Docker контейнерлерінің статусын тексеру: `docker ps` | Кезекші әзірлеуші |
| **3** | Егер контейнер өшіп қалса, қайта қосу: `docker compose up -d` | Кезекші әзірлеуші |
| **4** | Егер қате кодтан болса, соңғы өзгерісті кері қайтару: `git revert HEAD` және деплой жасау. | Кезекші әзірлеуші |
| **5** | Егер дерекқор құласа, соңғы backup-тан қалпына келтіру (Restore). | Backend әзірлеуші |
| **6** | Жағдай тұрақталған соң, Postmortem жазу үшін инцидентті тіркеу. | PM |
